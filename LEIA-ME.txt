CONTROLO HORAS E COMPENSAÇÕES
==============================

Versão final de teste 1.0, preparada para GitHub Pages e instalação no telemóvel.

PRINCIPAIS FUNCIONALIDADES
- Dashboard mensal e anual.
- Importação de folhas Excel (.xlsx e .xlsm).
- Deteção de duplicados e histórico das folhas importadas.
- Cálculo das horas extra pelos multiplicadores configurados.
- Salário base bruto de 1 500 €.
- Segurança Social do trabalhador configurada em 11%.
- IRS estimado para não casado, sem dependentes, Continente.
- Ajudas de custo e alojamento separados, sem descontos.
- Saldo conjunto de férias e compensações.
- Acréscimo anual automático de férias.
- Backup e restauro dos dados.
- Instalação PWA e funcionamento offline.

PUBLICAR NO GITHUB
1. Extraia o ZIP.
2. No repositório, escolha Adicionar ficheiro > Carregar ficheiros.
3. Envie TODOS os ficheiros extraídos para a raiz do repositório.
4. Confirme as alterações.
5. Em Configurações > Páginas, publique a ramificação principal e /(raiz).
6. Aguarde a atualização do GitHub Pages.

ATUALIZAÇÃO
Ao substituir os ficheiros no mesmo repositório, a aplicação mantém o mesmo endereço.
No telemóvel pode ser necessário fechar e voltar a abrir a aplicação para receber a versão nova.

DADOS
Os dados continuam guardados localmente em cada dispositivo. A sincronização PC-telemóvel ainda não está incluída.
